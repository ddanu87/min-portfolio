Royal Click Fighter

Klik på mønter, terninger og stjerner for at få point. Undgå bomberne. Demoen ligger internt i portfolioen, så linket virker direkte på GitHub Pages.

Spilmekanik

Gode elementer giver point. Dårlige elementer fjerner liv. Spillet slutter ved 10 point, 0 liv eller når tiden løber ud.

JavaScript

Demoen bruger state, timers, click-events, tilfældige elementer og DOM-opdatering af point, liv og resultat.

Responsivt layout

Spilområdet bruger 16:9-format, så det skalerer på mobil og desktop uden at miste formen.
