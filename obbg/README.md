# OBBG — Online Betting Board Games

OBBG is a frontend prototype for a peer-to-peer cultural board game platform.

## Important

This prototype does not use real money. All balances, stakes and payouts are demo-only.

A real-money version would require legal review, gambling licensing, age verification, KYC, AML checks, responsible gaming controls, payment compliance and operational approval before launch.

## Features

- Landing page
- Fake login
- Dashboard
- Game lobby
- Demo wallet
- Match setup
- Match room
- Demo payout logic
- Leaderboard
- Profile
- Responsible gaming page
- Legal roadmap page

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage

## How to run

Open `index.html` in a browser.

## Prototype goal

To demonstrate the product concept, user flow, fairness model and future legal roadmap for a peer-to-peer cultural board game platform.
