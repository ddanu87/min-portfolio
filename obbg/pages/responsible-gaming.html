Safety first

Responsible gaming

This page explains the controls a real-money version would need. The prototype itself uses demo coins only.

OBBG is not operating real-money gambling in this prototype. No real money can be deposited, withdrawn or won.

Age verification

Real-money gaming requires verified age controls before access.

KYC

Users would need identity checks before real-money activity.

AML checks

Transactions would require anti-money laundering monitoring.

Deposit limits

Users would need limits before playing with real money.

Self-exclusion

A real version would need exclusion tools and blocking flows.

Match transparency

Match history, replay logic and dispute handling would need clear records.

Anti-cheat

Game state must be validated server-side in a production version.

Disputes

Users need a clear process if a match result is challenged.

Legal approval

Real-money launch can only happen through the correct license or licensed partner.
