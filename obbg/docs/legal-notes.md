# Compliance Notes

This repository contains a demo-only interface prototype.

The prototype must stay limited to:

- demo coins
- fake balances
- local browser storage
- no deposits
- no withdrawals
- no payment providers
- no cash prizes
- no real-money play

A future regulated version would need professional legal review before any public launch. The scope would need to cover identity checks, age checks, transaction monitoring, player protection tools, limits, dispute handling, data logging and approval from the relevant authority or licensed partner.

The current prototype is only for product design, user flow, pitch and technical demonstration.
