Mine projekter

Fire projekter fra 1. semester. Hvert projekt viser opgave, proces, løsning, læring og refleksion.

Tema 2: Grundlæggende web / Computersite

HTMLCSSResponsivt design

Hvad: Et computersite med flere sider, navigation, tekst og billeder.

Hvorfor: Projektet viser grundlæggende webudvikling med HTML, CSS og filstruktur.

Hvordan: HTML bruges til struktur, og CSS bruges til layout, farver, typografi og responsivt design.

Læring: Jeg lærte, hvordan struktur og styling arbejder sammen i et website.

Dette projekt viser fundamentet for resten af semesteret: struktur, layout og navigation.
Tema-dokumentation · Kodeforklaring · Billeder

Tema 3: Sandkassesite / Emnesite - OBBG.dk

UX/UIResearchFigmaBrugertest

Hvad: Et fiktivt emnesite om OBBG.dk med fokus på digital brugeroplevelse, visuel identitet og tydelig navigation.

Hvorfor: Projektet viser, hvordan et digitalt koncept kan udvikles med research, målgruppe, brugerflow og test.

Hvordan: Jeg arbejdede med research, moodboard, styletile, wireframes, prototype, brugertest og kodet site.

Læring: Jeg lærte, at UX/UI handler om at forbinde brugerbehov, struktur, visuelt design og teknisk løsning.

Det rigtige materiale til OBBG.dk er Figma-processen: moodboard, research, wireframes, prototype, test og kode.
Tema-dokumentation

Tema 4: Animation og spil / Royal Click Fighter

JavaScriptAnimationSpil

Hvad: Royal Click Fighter er et klikbaseret browserspil.

Hvorfor: Projektet viser JavaScript, events, timer, point, liv og brugerfeedback.

Hvordan: Jeg brugte papirprototype, aktivitetsdiagram, HTML, CSS og JavaScript.

Læring: Jeg lærte, hvordan JavaScript kan styre interaktion og spiltilstande.

Projektet var vigtigt, fordi det gjorde JavaScript konkret gennem regler, point, liv og feedback.
Tema-dokumentation · Spildokumentation · Feedback

Tema 5: Virksomhedssite / Bird Bar

GruppearbejdeResearchUXKodning

Hvad: Et virksomhedssite for Bird Bar udviklet som gruppeprojekt.

Hvorfor: Projektet viser sammenhæng mellem afsender, målgruppe, indhold, visuel identitet og responsivt website.

Hvordan: Vi arbejdede med research, målgruppe, moodboard, wireframes, prototyper, billeder, HTML, CSS og test.

Læring: Jeg lærte, at et virksomhedssite skal koble virksomhedens stemning med brugerens behov og den tekniske løsning.

Det rigtige materiale til dette projekt er Bird Bar-processen: research, planlægning, prototyper, færdigt produkt, kode og test.
