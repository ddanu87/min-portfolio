Tema 2 - Mobilsite

Fra mobilsite til desktop: HTML, CSS, wireframe, layoutdiagram og responsivt layout.

Dokumentation

KravDe 5 siderProcesTilbage til Tema 2

Opgave

Jeg skulle arbejde videre på mobilsitet, så det også virkede på desktop. Siden skulle følge udleveret wireframe og layoutdiagram, og det færdige site skulle uploades via GitHub.

Krav fra opgaven

  • Sitet skulle bestå af 5 sider.
  • Siderne skulle følge udleveret wireframe og layoutdiagram.
  • Tekst og billeder var udleveret, plus eget foto/tekst på min_computer.html.
  • Sitet skulle have farver og to forskellige fonte.
  • CSS skulle deles op i styling og layout. I min mappe ligger det som style.css og layout.css.
  • HTML skulle validere uden fejl.
  • Alle sider skulle have <meta name="robots" content="noindex">.

De 5 sider

  • Forside: introduktion og navigation.
  • Min computer: eget foto/tekst og personlig del af opgaven.
  • Operativsystemer: indholdsside med tekst og struktur.
  • Komponenter: forklaring af computerens dele.
  • Galleri: billedside med fokus på layout og visuel præsentation.

Færdig løsning

Resultatet blev et responsivt site om computere med navigation, tekst, billeder, galleri og siden “Min computer”. I portfolioen linker jeg til denne interne dokumentationsside, så Tema 2 stadig virker stabilt, selv hvis gamle eksterne projektlinks ændrer sig.

Proces

Jeg arbejdede først med struktur og sider i HTML. Derefter brugte jeg CSS til farver, fonte, spacing, layout og desktop-tilpasning. Undervejs testede jeg navigation, billeder og responsiv visning i browseren.

Læring

Jeg lærte, at en tydelig HTML-struktur gør CSS meget lettere at styre. Jeg lærte også, at mobile-first ikke stopper ved mobil: layoutet skal planlægges, så samme indhold fungerer på større skærme.

Refleksion

Hvis jeg skulle lave opgaven igen, ville jeg validere tidligere, lave bedre noter om layoutdiagrammet og teste kontrast/accessibility mere systematisk.
