Om dette portfolio

Dette portfolio dokumenterer mit arbejde og min læring fra 1. semester. Sitet viser projekter fra semesteret og forklarer opgave, proces, løsning, læring og refleksion for hvert tema.

Portfolioet er opbygget med HTML, CSS og JavaScript, og det er designet til at være responsivt på mobil, tablet og desktop.

Der er fokus på struktur, dokumentation og faglig refleksion, så besøgende hurtigt kan forstå, hvad jeg har lavet, og hvad jeg har lært.

Fokusområder

Webudvikling

HTML, CSS, semantisk struktur, layout, navigation og responsivt design.

UX/UI

Brugerforståelse, wireframes, prototyper, brugertest og visuel identitet.

JavaScript

Interaktion, mobilmenu og mindre animationer til bedre brugeroplevelse.

Refleksion

Hvad jeg har lært, hvad der var svært, og hvad jeg vil forbedre fremadrettet.
