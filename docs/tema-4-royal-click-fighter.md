# Tema 4 - Royal Click Fighter

## Hvad
Royal Click Fighter er et klikbaseret browser-spil lavet med HTML, CSS og JavaScript.

## Hvorfor
Projektet blev lavet for at træne animation, spilmekanik, JavaScript-events, timer, point og liv.

## Hvordan
Jeg startede med spilide, papirprototype og aktivitetsdiagram. Derefter byggede jeg spillet med HTML, CSS og JavaScript.

## Løsning
Spilleren klikker på gode objekter og undgår dårlige objekter. Spillet har neon/casino-stil.

## Regler
Spillet varer 20 sekunder. Spilleren vinder ved mindst 10 point og taber ved under 10 point eller ved at miste alle liv.

## Værktøjer
- HTML
- CSS
- JavaScript
- Papirprototype
- Aktivitetsdiagram
- Browser-test

## Læring
Jeg lærte JavaScript-events, DOM-manipulation, timer, point, liv og feedback.

## Refleksion
JavaScript krævede logisk tænkning. Jeg ville forbedre kodestruktur, sværhedsgrad, test og feedback.
