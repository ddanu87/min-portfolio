# Tema 4 - Royal Click Fighter

## Opgave
Klikbaseret browser-spil lavet med HTML, CSS og JavaScript.

## Proces
Spilide, papirprototype, aktivitetsdiagram, objekter, point, liv, timer og feedback.

## Løsning
Neon-inspireret spil hvor spilleren klikker på gode objekter og undgår dårlige objekter.

## Regler
Spillet varer 20 sekunder. Man vinder ved mindst 10 point.

## Læring
JavaScript-events, spilmekanik, timer, point, liv og feedback.

## Refleksion
Koden kunne forbedres med bedre
