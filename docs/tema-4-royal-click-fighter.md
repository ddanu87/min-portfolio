# Tema 4 - Royal Click Fighter

## Hvad

Royal Click Fighter er et klikbaseret browser-spil lavet med HTML, CSS og JavaScript.

## Hvorfor

Projektet blev lavet for at træne animation, spilmekanik, JavaScript-events, timer, point og liv.

## Interne portfolio-links

- `royal-click-fighter.html` - spilbar demo i portfolioen
- `tema-4-animation.html` - samlet dokumentation
- `tema-4-animation.html#grafik` - grafik, wireframe og proces
- `tema-4-animation.html#teknik` - teknisk forklaring og spilflow

De interne links erstatter de gamle eksterne Tema 4-links, så projektet er mere stabilt til eksamen og GitHub Pages.

## Hvordan

Jeg startede med spilidé, papirprototype og aktivitetsdiagram. Derefter byggede jeg spillet med HTML, CSS og JavaScript.

## Løsning

Spilleren klikker på gode objekter og undgår dårlige objekter. Spillet har neon/casino-stil, point, liv, timer og vinder-/taberflow.

## Regler

Spillet varer 20 sekunder. Spilleren vinder ved mindst 10 point og taber ved under 10 point, ved at miste alle liv eller når tiden løber ud.

## Værktøjer

- HTML
- CSS
- JavaScript
- Papirprototype
- Aktivitetsdiagram
- Browser-test

## Læring

Jeg lærte JavaScript-events, DOM-manipulation, timer, point, liv og feedback. Jeg lærte også, at spil kræver tydelig struktur, fordi små fejl hurtigt kan påvirke hele brugeroplevelsen.

## Refleksion

JavaScript krævede logisk tænkning. Jeg ville forbedre kodestruktur, sværhedsgrad, test og feedback, hvis jeg skulle videreudvikle projektet.
