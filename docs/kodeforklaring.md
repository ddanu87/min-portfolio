# Kodeforklaring

Dette dokument forklarer, hvordan HTML, CSS og JavaScript bruges i portfolio-websitet.

## HTML

HTML bruges til at strukturere indholdet.

Jeg bruger blandt andet:

- nav til navigation
- main til hovedindhold
- section til opdeling af indhold
- article til projektkort
- footer til bundindhold

Semantisk HTML gør strukturen mere overskuelig og hjælper både browser, søgemaskiner og accessibility.

## CSS

CSS bruges til at styre websitets visuelle udtryk.

Jeg bruger CSS til:

- farver
- typografi
- spacing
- layout
- grid
- flexbox
- responsivt design
- hover-effekter
- kortlayout

## JavaScript

JavaScript bruges til mobilmenu og mindre interaktioner.

JavaScript gør, at menuen kan åbnes og lukkes på små skærme. Det forbedrer brugeroplevelsen på mobil.

## Responsivt design

Sitet er lavet, så det fungerer på både mobil, tablet og desktop.

Jeg bruger media queries i CSS til at ændre layoutet på mindre skærme.
