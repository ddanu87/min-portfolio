# Tema 2 - Computersite

## Opgave
Et website bygget for at lære HTML, CSS, filstruktur og navigation.

## Proces
Indholdet blev delt op i sider. Designet blev styret med CSS.

## Løsning
Et simpelt computersite med navigation, tekst, billeder og responsivt layout.

## Læring
HTML skaber struktur. CSS styrer layout, farver, typografi og spacing.

## Refleksion
Jeg ville teste mobilvisning tidligere og dokumentere processen mere løbende.
