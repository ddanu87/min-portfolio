# Tema 2 - Computersite

## Hvad
Jeg lavede et computersite med flere sider, navigation, tekst, billeder og responsivt layout.

## Hvorfor
Projektet blev lavet for at lære grundlæggende webudvikling og forstå, hvordan HTML og CSS arbejder sammen.

## Hvordan
Jeg byggede siden med HTML til struktur og CSS til styling. Jeg arbejdede med filstruktur, navigation, layout, typografi, farver og spacing.

## Løsning
Løsningen blev et simpelt website med overskuelig navigation og tydelig opdeling af indhold.

## Værktøjer
- HTML
- CSS
- VS Code
- Browser-test
- GitHub

## Læring
Jeg lærte, at HTML skaber struktur, og at CSS styrer layout, farver, typografi og afstande. Jeg lærte også, at filstruktur gør et site lettere at vedligeholde.

## Refleksion
Hvis jeg skulle lave projektet igen, ville jeg teste mobilvisning tidligere og dokumentere processen mere løbende.
