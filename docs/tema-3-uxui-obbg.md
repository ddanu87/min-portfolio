# Tema 3 - Sandkassesite / Emnesite - OBBG.dk

## Hvad

Jeg arbejdede med OBBG.dk som et sandkasse- og emnesite. Projektet er et digitalt koncept for en fiktiv platform om strategiske spil og betting. Fokus var ikke kun på det færdige website, men også på processen bag: research, målgruppe, moodboard, styletile, wireframes, prototype, brugertest og kodet løsning.

## Hvorfor

Projektet blev lavet for at lære, hvordan man udvikler et digitalt koncept ud fra brugerforståelse, designmetoder og test. Jeg skulle kunne begrunde valg omkring målgruppe, indhold, layout, visuel stil og brugeroplevelse.

## Proces

Processen bestod af research, ideudvikling, moodboard, styletile, wireframes, prototype, brugertest og kodning. Figma blev brugt til både dokumentation og prototype, mens det kodede site viste, hvordan designet kunne omsættes til HTML, CSS og JavaScript.

## Værktøjer

- Figma
- HTML
- CSS
- JavaScript
- Brugertest
- Browser-test

## Læring

Jeg lærte, at UX/UI kræver mere end et visuelt udtryk. Designet skal hænge sammen med målgruppe, brugssituation, indhold og navigation. Brugertest gjorde det tydeligere, hvor brugeren forstod løsningen, og hvor designet kunne forbedres.

## Refleksion

Hvis jeg skulle arbejde videre med OBBG.dk, ville jeg gøre testresultaterne endnu mere konkrete, forbedre accessibility og arbejde mere med at skære indholdet til, så brugerens første indtryk bliver skarpere.
