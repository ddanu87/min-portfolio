# Mundtlig præsentation - 5 minutter

## 0:00-0:30 Intro

Mit portfolio viser mit arbejde og min læring fra 1. semester på multimediedesign. Jeg har valgt at strukturere sitet med forside, portfolio, proces og om mig, så brugeren hurtigt kan forstå, hvem jeg er, hvad jeg har lavet, og hvad jeg har lært.

## 0:30-1:30 Proces

Før udviklingen gennemgik jeg eksamenskravene og samlede mine projekter fra semesteret. Under udviklingen arbejdede jeg med struktur, navigation, indhold og responsivt design. Efter udviklingen testede jeg siderne og vurderede, om hvert projekt tydeligt viste opgave, proces, løsning, læring og refleksion.

## 1:30-2:30 Projekter

Jeg viser fire centrale projekter: computersite fra grundlæggende web, UX/UI-projektet OBBG.dk, Royal Click Fighter fra animation og spil, og virksomhedssitet fra gruppearbejde. De viser tilsammen HTML, CSS, JavaScript, UX/UI, designproces, brugertest og refleksion.

## 2:30-3:30 Teknologi

Sitet er udviklet med HTML, CSS og JavaScript. HTML bruger jeg til struktur, CSS til layout, farver, typografi og responsivt design, og JavaScript til mobilmenu og interaktion. Jeg har uploadet projektet til GitHub og publiceret det via GitHub Pages.

## 3:30-5:00 Refleksion

Mit semester har været påvirket af sygdom og fravær, især i nogle gruppeprocesser. Det har gjort processen mere ujævn, men det har også lært mig, hvor vigtigt det er at kommunikere tydeligt, dokumentere løbende og skabe struktur. Hvis jeg skulle forbedre portfolioet, ville jeg lave flere brugertests, dokumentere processen mere systematisk og arbejde mere med accessibility.
