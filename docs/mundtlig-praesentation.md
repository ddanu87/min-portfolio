# Mundtlig præsentation - 5 minutter

## Intro
Portfolioet viser mit arbejde og min læring fra 1. semester.

## Før udviklingen
Jeg læste kravene og samlede projekter, billeder, links og noter.

## Under udviklingen
Jeg byggede sitet med HTML, CSS og JavaScript.

## Projekter
Tema 2 viser HTML og CSS. Tema 3 viser UX/UI og Figma. Tema 4 viser JavaScript og spil. Tema 5 viser virksomhedssite og gruppearbejde.

## Efter udviklingen
Jeg testede navigation, links, billeder, responsivt layout og GitHub Pages.

## Refleksion
Jeg har lært, at portfolioet skal vise både løsning, proces og læring. Fremadrettet vil jeg dokumentere mere løbende og teste tidligere.
