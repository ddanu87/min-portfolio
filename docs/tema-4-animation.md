# Tema 4 - Animation og spil / Royal Click Fighter

## Hvad

Royal Click Fighter er et klikbaseret browser-spil i neon/casino-stil. Projektet handler om animation, interaktion, JavaScript-events, point, liv, timer og spiltilstande.

## Proces

Jeg startede med spilidé, papirprototype og aktivitetsdiagram, så spillets flow var tydeligt før kodning. Derefter byggede jeg spillet op med HTML, CSS og JavaScript.

Spillet bruger klik-events, gode og dårlige elementer, point, liv, timer, start/reset og feedback til brugeren.

## Værktøjer

- HTML
- CSS-animationer
- JavaScript
- Papirprototype
- Aktivitetsdiagram
- Browser-test

## Læring

Jeg lærte, hvordan JavaScript kan styre interaktion, tilstande og feedback i en brugergrænseflade. Jeg fik også erfaring med, at et spil kræver tydelige regler, tydelig respons og en enkel struktur, som brugeren kan forstå hurtigt.

## Refleksion

Hvis jeg skulle forbedre projektet, ville jeg opdele JavaScript-koden mere, teste spillets flow mere systematisk og gøre feedback endnu tydeligere med lyd eller stærkere animationer.
