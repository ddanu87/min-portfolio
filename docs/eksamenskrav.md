# Eksamenskrav og hvordan portfolioet opfylder dem

Dette dokument forklarer, hvordan mit portfolio-website er bygget op i forhold til kravene for 1. semester portfolioeksamen.

Portfolioet skal vise mit arbejde og min læring fra 1. semester. Sitet har mig som afsender, og besøgende skal hurtigt kunne forstå, hvad jeg har lavet, hvordan jeg har arbejdet, og hvad jeg har lært.

Portfolioet opfylder kravene ved at indeholde:

- en forside med tydelig introduktion og navigation
- en portfolio-side med temaer og projekter fra 1. semester
- løsning, proces, læring og refleksion for hvert tema
- links, tekst og dokumentation for hvert tema
- en om mig-side
- HTML, CSS og JavaScript
- responsivt design
- GitHub Pages-link
- public GitHub repository

## Forside

Forsiden introducerer portfolioet og forklarer, at sitet viser projekter, proces og refleksion fra 1. semester.

## Portfolio

Portfolio-siden viser fire centrale projekter:

- Tema 2: Grundlæggende web
- Tema 3: UX/UI
- Tema 4: Animation og spil
- Tema 5: Virksomhedssite

Hvert projekt beskrives med:

- opgave
- proces
- løsning
- læring
- refleksion
- dokumentation

## Proces

Proces-siden beskriver arbejdet før, under og efter udviklingen af portfolioet. Den forklarer også sygdom, fravær og gruppearbejde som en del af min refleksion.

## Om mig

Om mig-siden viser mig som afsender og beskriver min uddannelse, mine kompetencer og hvad jeg har fået ud af 1. semester.

## Teknologi

Sitet er udviklet med HTML, CSS og JavaScript.

HTML bruges til struktur.
CSS bruges til layout, typografi, farver og responsivt design.
JavaScript bruges til mobilmenu og simple interaktioner.
