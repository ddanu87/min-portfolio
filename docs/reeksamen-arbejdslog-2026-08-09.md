# Reeksamen - arbejdslog 9. august 2026

## Formål

Denne fil dokumenterer den afsluttende gennemgang af min portfolio dagen før aflevering. Jeg brugte ChatGPT som teknisk og redaktionelt hjælpeværktøj under gennemgangen, mens mine semesterprojekter og mine egne materialer var grundlaget.

Det her er ikke en konstrueret semester-dagbog. Det er en konkret log over det arbejde, der faktisk blev udført i repository under den afsluttende reeksamensrunde.

## 1. Eksamenskrav blev kontrolleret

Eksamensmaterialet blev sammenholdt med repository. Det centrale afleveringskrav blev identificeret som:

- portfolio på GitHub Pages
- public GitHub repository med de samme filer

Repository blev kontrolleret som public.
