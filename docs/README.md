## Om dokumentationen

Noget af dokumentationen er lavet retrospektivt i forbindelse med reeksamen, fordi min oprindelige proces ikke var dokumenteret godt nok. Retrospektive dokumenter beskriver derfor det materiale, de valg og de fejl, som kan ses i mine faktiske projektfiler. De skal ikke læses som en påstand om, at jeg førte en komplet dagbog under hele semesteret.

AI er brugt som støtte til at gennemgå og strukturere materialet. AI bruges ikke som bevis for aktiviteter, jeg ikke kan dokumentere.
