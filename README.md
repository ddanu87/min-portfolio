# Danusan Padmarajah - 1. semester portfolio

## Formål
Dette repository indeholder mit portfolio-website til 1. semester på multimediedesign. Portfolioet skal vise, hvad jeg har lavet, hvordan jeg har arbejdet, og hvad jeg har lært.

## Links til aflevering
- Live website: https://ddanu87.github.io/min-portfolio/
- GitHub repository: https://github.com/ddanu87/min-portfolio

## Krav fra eksamensinformationen
Portfolioet skal indeholde:
- en forside med klar introduktion og navigation
- en portfolio-side med temaer fra 1. semester
- løsning, proces og læring for hvert tema
- links, tekst og billeder for hvert tema
- en Om mig-side med afsender, uddannelse, erfaring og læring
- HTML, CSS og JavaScript udviklet fra bunden
- responsivt design og mobile-first tankegang
- dokumentation af kode, proces, test og valg

## Sider
- `index.html` - forside og introduktion
- `portfolio.html` - fire projekter fra 1. semester
- `proces.html` - før, under og efter udviklingen af portfolioet
- `om-mig.html` - afsender, kompetencer og refleksion

## Projekter
1. Tema 2 - Grundlæggende web / Computersite
2. Tema 3 - UX/UI / OBBG.dk
3. Tema 4 - Animation og spil / Royal Click Fighter
4. Tema 5 - Virksomhedssite

## Teknologi
- HTML til struktur
- CSS til layout, typografi, farver og responsivt design
- JavaScript til mobilmenu og interaktion
- Figma til design og prototyper
- GitHub til versionsstyring
- GitHub Pages til publicering

## Dokumentation
Dokumentationen ligger i `docs/`. Den forklarer krav, proces, billeder, AI-brug, kode og de fire projekter.

## Vigtig afgrænsning
Royal Click Fighter er mit spil. Gravel Maniac er ikke mit spil og må kun nævnes som feedbackarbejde, hvis det bruges som dokumentation.

## AI-brug
AI er brugt som støtte til struktur, formulering, overblik og dokumentation. AI er ikke brugt som erstatning for egne projekter. Indholdet er kontrolleret og tilpasset mine egne projekter.
