# 1. Semester Portfolio – Multimediedesign

Dette repository indeholder mit portfolio-website til 1. semester på multimediedesigneruddannelsen.

Portfolioet er udviklet som en samlet præsentation af mit arbejde, min proces og min læring gennem 1. semester. Formålet med sitet er at vise, hvordan jeg har arbejdet med grundlæggende webudvikling, brugergrænseflader, brugeroplevelser, indholdsstruktur, visuel identitet og refleksion over egen læring.
